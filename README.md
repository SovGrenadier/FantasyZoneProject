# Fantasy Zone

(Menu)
Z - Add credit
X - Player one button
I - Give Player Invisibility
B - Give Player Slow Bullets
N - Stop enemy spawn rate from speeding up

(Ingame)
UP Arrow - Move up
Right Arrow - Move right
Left Arrow - Move left
DOWN Arrow - Move down
X - Shoot
Z - Drop Bomb
